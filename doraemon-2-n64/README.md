# Doraemon 2: Nobita and the Temple of Light
## English Translation — Version 1.0

Explore a mysterious world with Doraemon and his friends, collect gadgets, solve
puzzles and make your way through the temples. This English fan translation makes
the Japanese Nintendo 64 adventure playable in English.

## What’s included

- English dialogue, cutscenes, menus, item names and pickup messages.
- Translated graphical labels that fit the original game’s style.
- Clear day symbols in the Status menu, based on the in-game HUD symbols.
- Improved text spacing, line wrapping and hint readability.

Version 1.0 is the playable release. The original game’s Japanese voice acting is
retained; this is a text and graphics translation, not an English dub.

## Which file do I need?

**Already have the patched ROM?** Open this file in your Nintendo 64 emulator:

`Doraemon 2 - Nobita and the Temple of Light (English v1.0).z64`

You do not need to apply the patch to it again.

**Want to patch your own original copy?** Use:

`Doraemon 2 - Nobita and the Temple of Light (English v1.0).bps`

The BPS file contains the translation changes. It is not a playable game on its own.

## How to apply the patch

You need an unchanged Japanese ROM named:

`Doraemon 2 - Nobita to Hikari no Shinden (Japan).z64`

1. Keep a backup of your original ROM.
2. Open [Rom Patcher JS](https://www.marcrobledo.com/RomPatcher.js/) in your browser.
3. Beside **ROM file**, choose your original Japanese `.z64` file.
4. Beside **Patch file**, choose the English v1.0 `.bps` file.
5. Click **Apply patch** and save the new ROM.
6. Open the new ROM in your Nintendo 64 emulator and enjoy!

If the patcher says the ROM does not match, check that you selected the original
Japanese game, not an earlier English version or an already patched copy.
Renaming a different ROM to `.z64` will not make it match. The file checks below
help identify the correct copy.

## Playing and saving

This release has been checked using Mupen64Plus with the Glide64mk2 graphics
plugin. Other emulator and hardware setups may behave differently.

Use the game’s normal save feature as you play. Keep a backup before changing
versions. Emulator save states can depend on the emulator and ROM version; if an
old state behaves strangely, try loading your normal in-game save instead.

For this project’s existing setup, `launch_game.sh` now opens v1.0, and the current
manual save-state slots have already been kept compatible.
