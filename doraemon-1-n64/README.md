# Doraemon: Nobita and the Three Spirit Stones

**English fan translation · Version 1.0 · Nintendo 64**

## About the game

Join Doraemon, Nobita, and their friends on a colorful 3D adventure. Explore different lands, use Doraemon’s gadgets, meet new characters, and take on the Demon King in a quest for the Three Spirit Stones. The game was originally released in 1997.

## About this translation

This release translates story dialogue, menus, gadget names and descriptions, selected in-game graphics, and the title logo. The project owner has completed a playthrough. The translation aims to make the game natural and readable in English; some text or artwork may remain untranslated.

## How to apply the patch

You’ll need a clean Japanese copy of the game and the free **Floating IPS (Flips)** patching program.

1. Keep your Japanese game file safe; do not overwrite it.
2. Open Floating IPS and choose **Apply Patch**.
3. Choose `Doraemon - Nobita and the Three Spirit Stones v1.0.bps` from this folder.
4. When prompted, choose your clean Japanese game file.
5. Choose where to save the new game. You can name it `Doraemon - Nobita and the Three Spirit Stones v1.0.z64`.
6. Open the new `.z64` file in an N64 emulator.

If the patcher says the files do not match, check that you selected the Japanese version of the game and that your original file is complete and unmodified. If you already have the translated `.z64` included here, you can play it without applying the patch.
