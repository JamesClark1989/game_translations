# Game Translations

English fan translations of Japanese games, created with AI assistance and human review and playtesting.

This repository hosts translation patches, screenshots and patching instructions. No original or modified game ROMs are included.

## Available translations

### Shin SD Gundam Gaiden: Knight Gundam Monogatari

- Platform: Nintendo Game Boy, with Super Game Boy support
- Original publisher: Bandai
- Original release: 1994, Japan
- Translation language: English
- Patch version: 1.0
- Author: mr_sausage
- Status: Full English playthrough completed on Game Boy hardware, with no progression-blocking issues reported.

The translation includes story dialogue, menus, item descriptions, puzzle hints, title graphics and Super Game Boy border lettering. The English script aims for natural, readable dialogue while preserving the original meaning. Original gameplay mechanics and puzzles are preserved.

### Download

Open this repository’s Releases section and download
knight_gundam_english.bps from the Knight Gundam release.

### Applying the patch

1. Obtain your own unmodified copy of the Japanese game.
2. Open a BPS-compatible patcher.
3. Select the original ROM and knight_gundam_english.bps.
4. Save the patched ROM as a new file.
5. Play using a compatible emulator or Game Boy flash cartridge.

Keep your original ROM unchanged.

### Testing

A complete start-to-finish playthrough was completed on Game Boy hardware. Additional emulator testing covered selected gameplay sequences, dialogue and password restoration in Game Boy and Super Game Boy modes, including comparisons against the original Japanese ROM.

The BPS patch was also verified to reproduce the tested English build exactly.

A completed playthrough does not guarantee that every optional interaction or text variation is free of issues. Reports of typos, awkward wording or unexpected behaviour are welcome.

## AI assistance

These projects use AI assistance for translation drafting, ROM analysis, programming and testing, alongside human review and playtesting.

## Reporting issues

Please open an issue with:

- The game and patch version.
- The location or dialogue involved.
- What happened and what you expected.
- A screenshot, if available.
- Your emulator and version, or hardware setup.
- Reproduction steps or an in-game password, where useful.

Please do not attach ROM files.
