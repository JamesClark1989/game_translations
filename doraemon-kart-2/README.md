# Doraemon Kart 2 — English v1.0

An English fan translation of the 1999 Game Boy Color racing game. Race as Doraemon and friends, explore Story Mode, and collect gadgets.

## Play

Open **Doraemon Kart 2 (English v1.0).gbc** in your Game Boy Color emulator. This file is already patched. In the project folder, `launch_game.sh` opens it in Mednafen at 4× size.

## Apply the patch yourself

1. Start with an unmodified Japanese **Doraemon Kart 2**, revision 0. The original file is 1,048,576 bytes.
2. Open [ROM Patcher JS](https://www.marcrobledo.com/RomPatcher.js/).
3. Under **ROM file**, choose your original Japanese game file.
4. Under **Patch file**, choose **Doraemon Kart 2 (English v1.0).bps**.
5. Click **Apply patch**, save the downloaded game, and open it in your emulator.

If the patch reports a mismatch, your original game file is a different version or has already been modified. Use the original version listed above. Keep your original file unchanged.
