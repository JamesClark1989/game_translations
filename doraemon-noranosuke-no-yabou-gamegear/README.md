# Doraemon: Noranosuke’s Ambition — English v1.0

An unofficial English translation of **Doraemon: Noranosuke no Yabou** for the **Sega Game Gear**, originally released in Japan in **1993**. This version includes English dialogue, menus, gadget names and credits, plus an English title screen and readable lettering styled to suit the original artwork.

## Included files

- `Doraemon - Noranosuke's Ambition (English v1.0).gg` — the English game, ready to open in a Game Gear emulator.
- `Doraemon - Noranosuke's Ambition (English v1.0).ips` — the translation patch for your original Japanese ROM.
- Five screenshots at the Game Gear’s native resolution of **160 × 144**.

## How to patch

1. Keep a backup of your original Japanese ROM. Use the original file listed below; its checksums should match.
2. Open an IPS-compatible ROM patcher and select the original Japanese ROM and the included `.ips` patch.
3. Save the result as a new `.gg` file. Leave your original ROM unchanged.
4. Open the new English ROM in a Game Gear emulator, such as Mednafen.

If you use the included English ROM, you can skip patching. Do not apply the patch to an already translated ROM. A correctly patched file will match the English ROM checksums below.

## About this release

Version **1.0** packages the current translation and artwork. Automated ROM and patch checks passed, including confirming that the patch recreates the included English ROM exactly. A complete playthrough and final manual language review have not been completed.

The title screenshots show normal startup. The gameplay screenshot was captured through normal controller input. The Suneo and Shizuka dialogue screenshots show real translated game scenes selected using emulator controls; they were not reached through a complete playthrough.

This is a fan translation and is not an official Sega or Doraemon release.
